\# 🤖 ربات قیمت فولاد و فلزات



ربات تلگرام برای نمایش قیمت‌های لحظه‌ای محصولات فولادی، معدنی، فلزات گران‌بها و نرخ ارز.



\## 📦 محصولات پشتیبانی‌شده



\- آهن اسفنجی

\- شمش فولاد

\- میلگرد

\- گندله

\- کنسانتره سنگ آهن

\- فلزات گران‌بها (طلا، نقره، پلاتین)

\- نرخ ارز (آزاد و مبادله‌ای)



\## 🚀 راهنمای نصب



\### 1. دانلود کد

`bash

git clone https://github.com/YOUR\_USERNAME/steel-price-bot.git

cd steel-price-bot



\### 2. ساخت محیط مجازی

bash

python -m venv venv



فعال‌سازی محیط مجازی:

\- ویندوز: `venv\\Scripts\\activate`

\- لینوکس/مک: `source venv/bin/activate`



\### 3. نصب وابستگی‌ها

bash

pip install -r requirements.txt



\### 4. تنظیم متغیرهای محیطی

1\. کپی کردن فایل نمونه:

bash

cp .env.example .env



2\. ویرایش فایل `.env` و پر کردن مقادیر واقعی:



BOT\_TOKEN=توکن\_ربات\_تلگرام\_شما

METALPRICE\_API\_KEY=کلید\_API\_قیمت\_فلزات

ADMIN\_ID=شناسه\_کاربری\_تلگرام\_شما



\### 5. اجرای ربات

bash

python bot.py



\## 📋 دستورات ربات



\- `/start` - شروع کار با ربات

\- `/help` - راهنمای استفاده

\- `/admin` - پنل مدیریت (فقط ادمین)

\- `/update\_rates` - به‌روزرسانی دستی قیمت‌ها

\- `/status` - وضعیت ربات و آخرین به‌روزرسانی
